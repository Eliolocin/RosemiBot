TomoriBot can create media directly in chat: images, short videos, and spoken voice
messages. Ask her in plain language ("draw me a...", "send that as a voice message") or
use the `/generate` commands. Which capabilities are available depends on your configured
provider; see [Providers & Models](/features/setup-administration/providers-and-models/).

<CardGrid>
  <LinkCard title="Image Generation" href="/features/capabilities/media-generation/image-generation/"
    description="Text-to-image and image-to-image, with reference images from attachments, avatars, stickers, and emojis." />
  <LinkCard title="Video Generation" href="/features/capabilities/media-generation/video-generation/"
    description="Short text-to-video and image-to-video clips with customizable aspect ratios." />
  <LinkCard title="Voice: TTS & STT" href="/features/capabilities/media-generation/tts-and-stt/"
    description="Native Discord voice messages (text-to-speech) and audio transcription (speech-to-text)." />
</CardGrid>

:::note
Not every provider supports every capability. Local generation (ComfyUI, local voice
servers) is available on self-hosted instances; see [Self-Hosting](/self-hosting/).
:::

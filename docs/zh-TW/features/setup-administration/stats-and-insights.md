TomoriBot追蹤互動指標，以便你可以檢查活動趨勢、模型代幣使用、流行人格和工具調用，或呈現可共享的資訊圖表摘要卡。

## 文字儀表板

三個命令可開啟互動式選項卡式儀表板：

- `/stats personal`：查看自己的使用情況統計資料。
- `/stats persona`：查看該伺服器上特定人格的使用統計資料。
- `/stats server`：查看所有成員和人格的伺服器範圍統計資料。

每個儀表板都包含概述、人格、模型和成本、工具和命令、表達式、最喜歡的人員和排行榜的選項卡。

大多數子指令可讓你指定時間範圍視窗（例如7天、30天或所有時間）。個人統計資料的範圍可以是目前伺服器或你使用TomoriBot的所有伺服器。

文字儀表板是由呼叫者控制的持久公共訊息。他們將保持互動狀態，直到被解除或刪除，並且其他成員無法操縱你的儀表板控制。

:::note
令牌計數反映了供應商報告的可用情況（基於字元的估計僅適用於省略令牌指標的供應商）。成本數字會依照模型目錄中的標價對這些代幣進行定價，因此由於即時快取、供應商折扣或免費套餐配額，它們可能與你的實際帳單有所不同。
:::

## 可分享的資訊圖卡

運行`/stats generate`渲染精美的摘要圖像卡，你可以直接在聊天中分享：

- **個人包裹**：總結你的個人活動和最喜歡的人格。
- **人格親和力**：突出顯示該伺服器上特定人格的統計資料和頂級對話夥伴。
- **伺服器排行榜**：顯示伺服器範圍內的活動和會員排名。

在`/personal config`中隱私等級設定為`完整`的使用者無法產生個人統計卡。

有關卡片如何組成和渲染的詳細信息，請參閱[統計資訊圖表子系統](/en/architecture/subsystems/stats-infographic/)。

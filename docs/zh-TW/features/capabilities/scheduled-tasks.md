為自己設定提醒或安排定期公告，而無需離開聊天室。直接詢問機器人，她會為你創建時間表。計劃任務屬於主動人格。

提醒會在觸發時通知目標使用者，而自我任務則是人格在預定時間自行執行的操作。

## 建立一個

告訴她要在聊天中安排什麼：

```text
remind me to submit the report at 14:30
every Friday at 8pm, post a reminder that game night is starting
```

她解析請求的時間和重複次數。提醒在觸發時會ping目標使用者。任務是人格人格在時機到來時所執行的無聲的自我行動。

## 時區

預設情況下，絕對時間（例如“14:30”或“星期五晚上8點”）使用伺服器的時區（`/config` > `行為` > `一般行為`）。如果你使用`/personal config`設定自己的時區，機器人會自動轉換你的當地時間。「上午9點提醒我」表示你的上午9:00，即使伺服器位於另一個時區。相對時間（例如“2小時內”）不依賴時區並且始終是安全的。

當提醒針對的使用者的個人時區與伺服器的時區不同時，確認資訊會顯示兩個時鐘：伺服器時間和目標的本地時間。如果時間標籤錯誤，請使用後續訊息或`/scheduled-task edit`進行修復。

## 管理任務

兩個斜杠命令可讓你查看和調整現有計劃：

- `/scheduled-task edit`：更改任務內容、下次觸發時間、重複間隔或提醒目標。將時間間隔設為`0`以一次產生重複任務。
- `/scheduled-task remove`：刪除提醒或任務。

這兩個指令都會開啟一個選擇器，按人格、時間、頻道和重複次數列出你現有的計畫。

一個伺服器最多可以同時保留 100 個待處理的提醒與任務。達到上限時，TomoriBot 會通知你而不是繼續新增；使用 `/scheduled-task remove` 刪除舊的即可騰出空間。

## 傳送方式

僅在發送成功後，提醒才會標記為完成。如果交付中斷，TomoriBot會自動重試，而不會更改重複計劃。

如果交付重複失敗並達到重試限制，TomoriBot會發布一條警告，其中包含計劃的內容和任務ID。失敗的使用者提醒會對目標執行ping操作，因此不會錯過提醒，而失敗的自我任務不會發送ping。然後，一次性計劃將被刪除，而重複計劃在下一次發生時保持活動狀態，並且可以使用`/scheduled-task edit`或`/scheduled-task remove`進行管理。

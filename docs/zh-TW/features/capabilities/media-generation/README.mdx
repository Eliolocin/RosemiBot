TomoriBot可以直接在聊天中建立媒體：圖像、短視訊和語音訊息。用簡單的語言詢問她（“給我畫一個...”，“將其作為語音訊息發送”）或使用`/generate`命令。哪些功能可用取決於你配置的供應商；請參閱[供應商和型號](/zh-TW/features/setup-administration/providers-and-models/)。

    description="原生Discord語音訊息（文字轉語音）和音訊轉錄（語音到文字）。" />
</CardGrid>

:::note
並非每個供應商都支援所有功能。本機產生（ComfyUI，本機語音伺服器）可在自架執行個體上使用；請參閱[自架](/zh-TW/self-hosting/)。
:::

一個 AI 框架專案怎麼能沒有可愛的吉祥物與虛構故事？在設定裡，Tomori 是一種安卓機型，特徵是機械角、尾巴，以及顯眼的條碼標籤（通常掛在耳朵上）。她們能變換外形（這就是她為什麼能分裂成多個人格）。

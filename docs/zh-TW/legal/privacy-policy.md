本隱私權政策說明官方託管的 TomoriBot 執行個體如何處理資料。如果你是從這個儲存庫自架 TomoriBot，你的資料由你自己掌控；本文件是參考範本，不適用於你的自架部署。

「Server」、「Memories」、「Persona/Preset」、「Provider」、「Trigger」與「API Key」等詞彙定義於我們的[服務條款](/zh-TW/legal/terms-of-service/)。相關定義請參閱該文件。

## 隱私權概覽

- 我們不保留你的 Discord 聊天紀錄副本。TomoriBot 在回答時讀取最近的訊息，之後就丟棄它們。
- 如果啟用了短期記憶，TomoriBot 確實會儲存由那些對話衍生的簡短摘要。那些摘要會在一段時間沒有活動之後過期（預設 90 天）。
- 你刻意教導 TomoriBot 的一切（記憶、人格設定、上傳的文件）都會被儲存，直到有人刪除它。
- TomoriBot 回答時，會將你的提示詞與最近的脈絡送到該伺服器設定的 AI 供應商。那個供應商有自己的條款與隱私實務，我們無法控制。
- `/personal nuke` 會清除我們儲存的、關於你的一切，涵蓋每一個伺服器。

底下各節會逐一說明上述每一點的細節。

## 1）本政策涵蓋的範圍

本政策適用於官方託管的 TomoriBot 執行個體。伺服器管理員為某個 Server 設定 TomoriBot，但每一位訊息被 TomoriBot 處理的成員都受本政策涵蓋，無論他們本人是否執行過指令。

伺服器管理員在 `/setup` 期間接受服務條款，並在該處確認他們會讓成員取得這份資訊。任何成員都可以隨時用 `/legal privacy-policy` 與 `/legal terms-of-service` 讀取目前的政策。

## 2）我們儲存什麼

### 2.1）關於你

- 身分與偏好： 你的 Discord 使用者 ID、語言偏好與隱私退出狀態。
- 個人化設定： 你選擇的暱稱、代名詞、性別認同、稱呼方式、外貌標籤、模仿提示詞、角色參考圖片 URL、時區位移，以及訊息前綴與後綴的覆寫。
- 稱呼偏好： 每個人格應該怎麼稱呼你。
- 個人記憶： 你教導 TomoriBot 關於你自己的事實，或是在啟用個人記憶時它為你存下的事實。
- 聚光燈： 你為每個伺服器設定的個人聚光燈設定。
- 制約紀錄： 你透過 `/reward` 與 `/punish` 提供的文字與理由，它們會影響人格在該 Server 的行為。
- 使用計數： 你每天使用的指令、模型與工具次數，加上 token 總數，並以你、Server 與人格為鍵。這些資料驅動 `/stats`。

### 2.2）關於你的 Server

- 伺服器設定： 人格屬性、範例對話、觸發詞、供應商與模型選擇、頻道與身分組權限、額度、時區與功能開關。
- 伺服器記憶： 為整個 Server 教導 TomoriBot 的事實。它們可能描述成員，包括沒有親自寫下這些內容的成員。
- 表情符號與貼圖中繼資料： Discord ID、名稱、說明與格式旗標。圖片檔本身不會被儲存。
- 提醒： 提醒文字、目標使用者的 Discord ID 與暱稱、頻道、排程，以及任何重複設定。
- 短期記憶摘要： 當短期記憶啟用時，TomoriBot 會把由最近對話衍生的簡短摘要寫進資料庫，讓它能在觸發之間保持脈絡。這些摘要會在一段時間沒有活動之後刪除（預設 90 天）。
- 整合連結： Matrix 房間與頻道連結，以及管理員連接的任何 MCP 伺服器的 URL、探索到的工具名稱與加密的驗證權杖。

### 2.3）憑證

- 你選擇儲存的供應商 API 金鑰，在 Server 層級或個人層級。
- 自訂端點定義，包括端點 URL 與任何 bearer token。

所有憑證都以加密形式靜態儲存。

### 2.4）你上傳的內容

- 文件： 上傳到 Server 知識庫的檔案所萃取出的完整文字，連同檔名、媒體類型、大小，以及由那些文字產生的搜尋嵌入向量。
- 人格圖片： 頭像、立繪與角色參考圖片，儲存在物件儲存中，讓人格能一致地呈現。
- 語音樣本： 設定語音複製時的音訊樣本與其參考逐字稿。

### 2.5）營運紀錄

- 錯誤紀錄： 互動 ID、使用者與 Server ID、指令名稱、錯誤類型與堆疊追蹤。訊息內容與對話不會被記錄。保留 90 天。
- 效能指標： 用來維持服務健康的時間與資源樣本。保留 30 天。
- 人格訊息對應： 將送出的訊息連結到它所使用的人格立繪的 Discord 訊息與頻道 ID，讓 TomoriBot 能更新或清理自己的訊息。保留 30 天。

## 3）我們不儲存什麼

以下內容會在 TomoriBot 準備回覆時被讀取，但不會寫入我們的資料庫：

- Discord 訊息： 最近的頻道訊息（通常是最近 80 則）會在記憶體中被讀取以建立脈絡，並送到設定的供應商。回覆產生之後它們就被丟棄。如果啟用了短期記憶，摘要可能會另外保留，如第 2.2 節所述。
- 附件與媒體： 觸發期間分析的圖片、影片與個人檔案圖片都會在記憶體中處理並丟棄。
- Server 與頻道中繼資料： Server 名稱、說明、頻道名稱與主題每次都重新讀取。
- 上線狀態資訊： 你目前的活動或狀態，在可以取得時。
- 表情符號與貼圖圖片： 每次使用時都從 Discord 重新取得。

## 4）我們送給第三方的內容

- AI 供應商： 你的提示詞、上述的最近脈絡、人格資料與任何附件，都會送到該 Server 或為你設定的供應商，例如 Google、OpenRouter、NovelAI 或自訂端點。這涵蓋文字、視覺、嵌入、圖片、影片、語音與轉錄請求。他們的條款、隱私政策、安全篩選與保留規則適用於那些內容，我們無法控制。
- 搜尋供應商： 如果啟用了網頁搜尋，搜尋查詢與相關脈絡會送到設定的搜尋供應商。
- Matrix： 如果某個頻道設定了 Matrix 橋接，訊息會在 Discord 與連結的 Matrix 房間之間往返。

我們不販售個人資料。我們只在運作你使用的功能所需，或法律要求時分享它。

## 5）我們保留多久

| 資料 | 保留期 |
|---|---|
| 短期記憶摘要 | 最後一次活動之後 90 天（預設） |
| 錯誤紀錄 | 90 天 |
| 效能指標 | 30 天 |
| 人格訊息對應 | 30 天 |
| 第 2 節的其他所有內容 | 直到透過第 6 節的指令刪除為止 |

當 TomoriBot 從某個 Server 移除時，該 Server 的資料會被保留，讓設定在重新邀請之後仍然存在。想讓它消失的管理員，應該在移除 bot 之前執行 `/nuke`。

## 6）你的控制項

| 你想做什麼 | 指令 |
|---|---|
| 停止 TomoriBot 儲存關於你的個人記憶 | `/personal config` |
| 檢視或移除個別的個人記憶 | `/personal memories` |
| 檢視或移除伺服器記憶與文件 | `/memories` |
| 取得你的個人資料副本 | `/export personal config`、`/export personal memories` |
| 取得某個 Server 的資料副本 | `/export config`、`/export memories` |
| 將你的個人設定重設為預設值 | `/reset personal config` |
| 清除我們儲存的、關於你的一切，涵蓋每一個 Server | `/personal nuke` |
| 清除某個 Server 的資料（僅限管理員） | `/nuke` |

`/personal nuke` 會刪除你的個人記憶、個人化與稱呼設定、聚光燈、你儲存的供應商金鑰與個人端點、你註冊的模型、你的使用計數、你貢獻的人格制約，以及你建立或為你設定的任何提醒。在執行之前，有兩項後果值得了解：

- 你透過 `/reward` 與 `/punish` 貢獻的人格制約會影響人格在該 Server 對所有人的行為，所以移除它會改變共用的行為。
- 你教導的伺服器記憶與你上傳的文件屬於 Server，會被保留，但會移除你的作者身分。如果其中一項描述到你，請要求管理員用 `/memories` 移除它。

你的退出設定會刻意在清除之後存續，所以清除你的資料不會悄悄重新啟用關於你的收集。

對這些指令無法觸及的任何事情，請用第 9 節聯絡我們，我們會手動處理。

## 7）安全性

- 供應商 API 金鑰、bearer token 與 MCP 憑證都以加密形式靜態儲存。
- 資料庫連線使用帶憑證驗證的 TLS。
- 資料庫存取僅限於 bot 的執行環境，以及具備基礎設施存取權的操作人員。

沒有系統是完全安全的。請不要給 TomoriBot 高度敏感或受法規規範的資訊。

## 8）兒童資料

TomoriBot 並非針對低於 Discord 在其所屬國家要求的最低年齡（至少 13 歲）的任何人。我們不會在知情的情況下收集低於該年齡使用者的資料。如果你認為我們持有低於適用的最低年齡者的資料，請用第 9 節聯絡我們，我們會刪除它。

本政策適用於Discord上的TomoriBot官方託管服務，包含個人使用、伺服器使用，以及由贊助額度支付的請求。若你自架TomoriBot，資料由你自行管理，本政策不適用於你的副本。

## 隱私重點

- TomoriBot會讀取近期訊息來回覆，並將相關脈絡傳給所選的AI供應商。我們不保存聊天紀錄副本，但選用的短期記憶功能會保存摘要。
- 我們保留你或伺服器選擇保存的設定、記憶和檔案。有些伺服器記憶可能描述未提供這些資訊的成員。
- 付費會員會增加帳號連結、贊助和使用紀錄，以提供權益並追蹤共用額度。我們不收集你的Patreon密碼或信用卡資料。
- 大部分已存資料可用指令查看或刪除。訂閱紀錄需要另外聯絡支援。刪除bot資料不會取消Patreon扣款。

## 1）本政策的適用對象

即使從未使用指令，只要TomoriBot會讀取其訊息的成員，也在適用範圍內。伺服器管理員必須告知成員bot及本政策的資訊。你可透過`/legal privacy-policy`與`/legal terms-of-service`閱讀最新文件，或查看[服務條款](/legal/terms-of-service/)。

## 2）保存的資料與用途

我們使用已存資料提供你選擇的功能、記住偏好、管理付費存取權，並維持服務運作。

### 2.1）帳號與偏好

我們保存你的Discord使用者ID、隱私選擇，以及你選擇儲存的個人檔案資訊與偏好。我們也保留用量總計，讓你查看個人、伺服器及其人格的統計。你儲存的偏好設定包含是否允許人格主動 @標註 你發起對話（來自人格的標註）。

### 2.2）記憶與伺服器設定

我們保存個人記憶與伺服器記憶、人格自訂內容、提醒和伺服器設定，以提供你設定的功能。

當人格自主開口發起對話時（Natural Nudges），我們會記錄說話的人格、頻道、是否有人回應以及被標註的成員。我們還會儲存該人格針對該對話的私密目標（其中可能提及該成員）。

選用的短期記憶會保存對話摘要。其他已存記憶會保留到刪除為止，也可能描述未撰寫該記憶的人。

### 2.3）API金鑰與連接服務

我們保存你為AI供應商、自訂端點及MCP伺服器提供的API金鑰、服務位址與驗證資料，以及Discord頻道與Matrix房間的連結。託管服務也管理訂閱存取所需的憑證。儲存的憑證均經過加密。

### 2.4）保存的檔案

我們保留知識庫文件的文字及檔案資訊，讓bot能搜尋文件。我們也保存人格圖片，以及聲音複製使用的語音樣本與逐字稿。

### 2.5）服務紀錄

錯誤與效能紀錄用於排查問題，可能包含Discord ID、指令名稱及錯誤詳情，但不含對話或訊息內容。我們也保存訊息識別碼，以管理bot送出的訊息。

### 2.6）會員與訂閱用量

連結Patreon會將你的Discord帳號與Patreon會員資格連接。我們會從Patreon取得方案、付款狀態及帳單日期，以判定你的權益。

我們保留贊助及其授權、額度與支出總計，以及請求的模型、功能、費用、token數量、時間和識別碼等資訊。受贊助伺服器的使用會與該伺服器關聯，並扣除贊助者的額度。

暫時的登入與會員更新紀錄用來保護帳號連結並防止重複更新。你自己的Patreon登入token在連結完成後不會保留。

## 3）會讀取但不保存的資料

TomoriBot為了回覆，會暫時讀取近期訊息、相關媒體、伺服器與頻道資訊，以及可取得的上線狀態。這些資料不會保存為聊天紀錄。短期記憶摘要及你主動保存的檔案依上述方式處理。

## 4）誰會收到你的資料

- **AI供應商：**所選供應商會收到文字、圖片、影片、語音或文件搜尋所需的提示詞、相關對話脈絡、人格資訊及媒體。在人格主動標註某人之前，伺服器的模型還會收到該成員的名字、目前活動和近期的個人記憶（除非該成員的隱私等級隱藏了這些資訊）。訂閱請求使用OpenRouter及所選模型的供應商。我們會向OpenRouter查核支出以管理額度。
- **Patreon：**連結即授權我們確認會員資格。Patreon提供帳號與會員更新；付款及付款資料由Patreon及其支付服務商處理。
- **搜尋供應商：**使用網路搜尋時，搜尋供應商會收到搜尋詞及相關脈絡。
- **Matrix：**設定橋接後，訊息會在連結的Discord頻道與Matrix房間之間共享。
- **託管與儲存服務商：**處理及保存執行TomoriBot所需的資料。

這些服務可能在你所在國家以外處理資料，並有各自的隱私與保留政策。我們不出售個人資料；僅為提供你使用的功能，或在法律要求時共享。

## 5）保留多久

| 資料 | 保留時間 |
|---|---|
| 短期記憶摘要 | 預設為最後活動後90天 |
| 錯誤紀錄 | 90天 |
| 效能紀錄與bot訊息識別碼 | 30天 |
| Natural Nudges 紀錄 | 30天；人格的私密目標最長保留90天 |
| Patreon會員更新紀錄 | 預設30天 |
| 已完成或過期的Patreon登入紀錄 | 預設一小時後可刪除 |
| 詳細訂閱用量 | 90天；若當期結束較晚，當期紀錄保留至該期結束 |
| 資料庫復原備份 | 七天 |
| 啟動時自動備份 | 最多五份；產生新備份時刪除舊備份 |
| 會員連結、存取狀態、贊助及受管理金鑰 | 連結期間；解除連結或清除請聯絡支援 |
| 解除連結後保留的會員識別碼與額度、支出總計 | 解除連結、付費期間結束及供應商金鑰刪除完成三者中，最晚發生之後90天 |
| 其他已存設定、記憶、憑證及上傳檔案 | 透過第6節的控制項刪除為止 |

到期紀錄會在排程清理時刪除。若有特定尚未解決的爭議或法律義務，我們可能延長保留相關帳務紀錄，並在不再需要時刪除。詳細用量刪除後，支出總計仍可能保留。已刪除資料可能留在保留中的備份內：資料庫復原備份七天後到期，啟動備份則保留到被替換。另行製作的復原或移轉副本會在相關工作完成後刪除。

移除bot會保留伺服器資料，以供重新邀請時使用；若要刪除，請先執行`/nuke`。取消扣款不會刪除會員紀錄。

## 6）查看、匯出或刪除資料

| 目的 | 操作位置 |
|---|---|
| 控制訊息可見性與個人記憶使用 | `/personal config` |
| 停止人格主動 @標註 你發起對話 | `/personal config` > `隱私` > `來自人格的標註` |
| 查看或移除個人記憶 | `/personal memories` |
| 查看或移除伺服器記憶與文件 | `/memories` |
| 匯出個人設定或記憶 | `/export personal config`、`/export personal memories` |
| 匯出伺服器設定或記憶 | `/export config`、`/export memories` |
| 重設個人設定 | `/reset personal config` |
| 跨伺服器清除下述個人資料 | `/personal nuke` |
| 清除伺服器資料（僅限管理員） | `/nuke` |

`/personal nuke`會刪除個人設定、記憶、已存供應商憑證與組態、使用次數，以及你建立或為你設定的提醒。刪除回饋也可能影響人格對其他成員的行為。

你提供的伺服器記憶與文件會保留，只移除作者關聯；請管理員用`/memories`刪除。若共享記憶或文件含有你的個人資料，而你無法讓對方刪除，請透過第9節直接聯絡我們。提出審查及刪除要求不需要管理員同意。

隱私設定會限制訊息可見性及個人化，但不會刪除既有記憶。清除資料後仍會保留隱私拒絕選項，不會悄悄重新啟用收集。你對來自人格的標註的選擇屬於個人化設定，因此 `/personal nuke` 會將其清除；如果事後仍想保持關閉，請在清除後再次將其關閉。

訂閱可透過訂閱面板查看額度、贊助，或停止贊助伺服器。續訂必須在Patreon取消；停止贊助或刪除bot資料都不會停止扣款。

如要存取、解除連結或清除訂閱紀錄，請透過第9節聯絡我們；一般匯出與`/personal nuke`不包含這些紀錄。解除連結會移除帳號連結、存取權、贊助及本機詳細用量，並要求刪除受管理的供應商金鑰。第5節所述的有限帳務紀錄仍可能保留。

## 7）如何保護資料

儲存的存取憑證均經過加密。資料庫連線經過加密並驗證伺服器身分。存取權限限於bot執行環境及有基礎設施存取權的運作人員。

沒有系統能保證完全安全。請避免提供極敏感或有特殊處理要求的資料。

## 8）兒童資料

TomoriBot不以未達所在國家Discord最低年齡（至少13歲）的人為對象。我們不會明知而收集低於該年齡者的資料。若你認為我們持有這類資料，請聯絡我們，我們會刪除。部分供應商及訂閱功能有較高年齡要求，詳見服務條款。

## 9）聯絡方式

隱私問題或指令無法處理的要求，請寄信至`bredrumb@gmail.com`，或在[TomoriBot官方支援Discord伺服器](https://discord.gg/bjCfHm9QsB)聯絡我們。個人資料或安全疑慮請透過電子郵件或私訊提出，不要發布在公開GitHub issue。

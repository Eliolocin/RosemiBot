## 用 `bun run launch` 啟動本機伺服器

不必手動啟動本機伺服器，改用 `bun run launch`，它會啟動指定的伺服器、等待它們就緒，然後自動以監看模式啟動 bot：

```sh
# Bot only, identical to bun run dev
bun run launch

# With the SearXNG and Crawl4AI Docker containers
bun run launch --searxng --crawl4ai

# With a local TTS server (venv must be set up first — see the Text-to-Speech guide below)
bun run launch --qwen3tts
bun run launch --fishs2
bun run launch --voxcpm2
bun run launch --cosyvoice3

# See all available flags
bun run launch --help
```

可用的旗標：`--searxng`、`--crawl4ai`、`--qwen3tts`、`--chatterbox`、`--irodoritts`、`--voxcpm2`、`--fishs2`、`--cosyvoice3`、`--moss`、`--whisperx`

Docker 容器（`--searxng`、`--crawl4ai`）會在第一次執行時建立，之後重複使用。Python 的 TTS 與 STT 伺服器需要事先設定好它們的 venv；請看[文字轉語音](/zh-TW/self-hosting/local-endpoints/text-to-speech/)與[語音轉文字](/zh-TW/self-hosting/local-endpoints/speech-to-text/)底下的個別設定指南。

Ctrl+C 會停止 bot 與任何 Python 伺服器行程。Docker 容器刻意維持運行。結束時請用 `docker stop searxng` 或 `docker stop crawl4ai` 手動停止它們。

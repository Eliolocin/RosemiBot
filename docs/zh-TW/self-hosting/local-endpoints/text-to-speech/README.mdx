直接在你的電腦上產生自然的語音訊息和字元語音，無需支付每個字元的費用或將音訊串流傳輸到第三方語音API。

TomoriBot將語音視為自訂端點功能。本地引擎作為HTTP伺服器在機器人外部運行並實現`POST /synthesize`；克隆引擎接收文字以及配置的參考音訊樣本，而支援VoiceDesign的引擎還可以接收自然語言指令。

## 設定流程

1. 從上面的卡片中選擇一個引擎並從`servers/tts/`設定其包裝器。
2. 在`/providers`中，選擇`Add New Custom Endpoint`並使用API相容性`tts-clone`。
3. 選擇已儲存的端點並使用其模型下拉清單新增其語音模型、語音來源模式和腳本標記。
4. 開啟`/config` > `模型` > Switch Models，選擇註冊的Speech模型。

## 網路存取
{/* anchor: network-access */}

所有TTS本機伺服器預設都綁定到`127.0.0.1`，所以只有同一台機器上的bot能連到它們。當TomoriBot在Docker或另一台機器上執行時，請為伺服器設定`TOMORI_TTS_HOST=0.0.0.0`，並用主機的位址註冊端點，例如`http://host.docker.internal:8015`。

這些伺服器沒有驗證機制：任何能連到該連接埠的人都能用你的GPU執行合成。只在可信任的網路中綁定到回送以外的位址；若要把伺服器公開到該網路之外，請在前方放一個具備驗證的反向代理。

每個伺服器都讀取自己的連接埠變數（`CHATTERBOX_PORT`、`QWEN3TTS_PORT`、`IRODORI_TTS_PORT`、`FISH_S2_PORT`、`VOXCPM2_PORT`、`COSYVOICE3_PORT`、`MOSS_TTS_PORT`），因此可以用同一個`.env`同時執行多個伺服器。`bun run launch`會把`.env`傳給它啟動的伺服器；手動啟動的伺服器只讀取其shell環境。

## 人格語音流程

對於克隆引擎，為每個人格添加並分配一個語音樣本：

1. 準備一個乾淨的剪輯，只有一個揚聲器，沒有背景音樂。每個引擎都有自己的最佳長度，根據型號從3到30秒不等；下面的每個引擎指南都帶有編號。
2. 在模型 > `TTS參數與語音`下開啟`/config`並上傳範例。接受任何音訊格式； TomoriBot將其轉換為單聲道WAV，最長130秒。
3. 當引擎從中受益時提供匹配的記錄。Fish S2 Pro將儲存的參考轉錄本轉發到克隆請求中，VoxCPM2將其用於更高保真度的終極克隆。
4. 在人格 > `語音`下開啟`/config`，然後選擇人格和語音樣本。

130秒上傳上限由TomoriBot強制執行。發送剪輯時，每個引擎都會套用自己的參考音訊限制，而這些限制差異很大，以至於適合一個引擎的剪輯可能會被另一個引擎拒絕或部分忽略。上傳長剪輯之前請檢查引擎指南。

上傳大小限制和時長上限是獨立的，並且首先執行大小檢查。未压缩的WAV立体声44.1 kHz的成本约为每分钟10 MB，因此130秒的DAW导出可能约为22 MB，并且会因太大而被拒绝，而同一剪辑的压缩导出则很容易适应。`SPEECH_SAMPLE_MAX_MB`提高了該大小限制（預設為10 MB）。对于较长的参考剪辑，请将其导出为FLAC、MP3或OGG，而不是WAV：TomoriBot在存储之前将任何可接受的格式转换为22.05 kHz的单声道WAV，因此压缩上传不会影响质量。

對於Qwen3-TTS、MOSS-VoiceGenerator、IrodoriTTS或VoxCPM2 VoiceDesign，請跳過音訊範例並使用`/config`中的人格 > `語音`儲存人格的自然語言語音描述。CosyVoice 3使用克隆模式和參考樣本，並透過`voice_instructions`接受一次性交付指示。

ElevenLabs使用者應在`/providers`中選擇`新增供應商`和`ElevenLabs`；它將語音和轉錄端點註冊在一起。

TomoriBot在合成之前從生成的語音腳本中剝離Discord自訂表情符號語法，例如`:pepega:`或`<:pepega:123456789012345678>`。除非語音端點使用IrodoriTTS的表情符號標記，否則Unicode表情符號也會被刪除。當Chatterbox Turbo和Fish S2 Pro等端點的腳本標記設定為`方括號標籤`時，會保留括號標記。

VoxCPM2使用`純文字`腳本標記。其語音設計和說話風格控制穿過TomoriBot的`instruct`字段，VoxCPM2包裝器將它們轉換為模型的原生帶括號的自然語言控制語法。

CosyVoice 3也使用`純文字`腳本標記。它將轉錄本支援的引用映射到零次克隆，將無轉錄本引用映射到跨語言克隆，並將`voice_instructions`映射到其指令條件路徑。內嵌括號標籤被刪除，因為CosyVoice指令適用於整個話語。

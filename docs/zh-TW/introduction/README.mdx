TomoriBot 是一套免費且開源的 Discord AI 代理與角色扮演系統。這個專案想把個人 AI 夥伴與角色扮演角色直接帶進 Discord 伺服器，靈感來自 SillyTavern 與 Discord 已停止服務的 Clyde。簡單說，她（或*它*）是一套放進 Discord 的 AI 代理加角色扮演框架：

![Tomori 公式](/img/docs/intro/00-tomori-formula.png)
<small style={{ display: 'block', textAlign: 'center', fontStyle: 'italic', color: 'var(--sl-color-gray-3)' }}>像是 Discord、SillyTavern 與 OpenClaw 三者的邪門三位一體</small>

讀作 Tomo(友)-Ri(里)，大致意思是「友人之家」。Tomori 是你專屬實用助理、可自訂夥伴，或角色扮演對象的家，無論在私訊裡，或是在你的 Discord 伺服器裡與所有人一起。她也是為初學者設計的，所以剛接觸 AI 代理的人也能跟著她一起學。

你現在就可以邀請公開執行個體，或自架自己的執行個體，完全掌控你的資料（更多資訊請看[快速開始](/zh-TW/introduction/quickstart/)）：

## TomoriBot 能做什麼？


<div class="feature-grid">
  <FeatureCard title="多個人格" img="/img/docs/intro/01-multiple-personas.png" href="/zh-TW/features/chatting-personality/multiple-personas/">
    在一個伺服器裡跑好幾個自訂角色，每一個都有自己的設定、記憶與頭像。看它們互相配合（或一起胡鬧）！
  </FeatureCard>
  <FeatureCard title="持久記憶" img="/img/docs/intro/02-memory.png" href="/zh-TW/features/knowledge/memory/">
    教她關於大家與你伺服器的事實，讓你的 Tomori 成長。她會跨對話記住這些事，個人記憶則會跟著你在不同伺服器之間移動。
  </FeatureCard>
  <FeatureCard title="媒體生成" img="/img/docs/intro/03-media-generation.png" href="/zh-TW/features/capabilities/media-generation/">
    直接在聊天中依提示詞或參考素材生成與編輯圖片、短影片與語音訊息。
  </FeatureCard>
  <FeatureCard title="代理式工具" img="/img/docs/intro/04-agentic-tools.png" href="/zh-TW/features/capabilities/tools-and-extensions/">
    TomoriBot 可以自己搜尋網頁、安排提醒、封鎖使用者、使用自訂 MCP 工具，還有更多。
  </FeatureCard>
  <FeatureCard title="完全本機設定" img="/img/docs/intro/05-fully-local-setup.png" href="/zh-TW/self-hosting/local-endpoints/">
    用本機 LLM、ComfyUI、SearXNG、本機語音伺服器與 MCP 打造完全屬於你自己的私人設定。
  </FeatureCard>
  <FeatureCard title="伺服器管理" img="/img/docs/intro/06-server-moderation.png" href="/zh-TW/features/setup-administration/server-moderation/">
    加入兼顧成本與安全的管理控制：額度、頻道與身分組白名單、思考紀錄，以及 BYOK 要求。
  </FeatureCard>
  <FeatureCard title="200+ 指令" img="/img/docs/intro/07-command-reference.png" href="/zh-TW/features/command-reference/">
    數百個原生 Discord 斜線指令，讓你深入自訂，從使用的提示詞到開放給誰的權限都涵蓋。
  </FeatureCard>
  <FeatureCard title="SillyTavern 支援" img="/img/docs/intro/08-sillytavern-support.png" href="/zh-TW/features/integrations/sillytavern-support/">
    匯入 SillyTavern 的提示詞預設集與角色卡，把現成的指示與角色直接帶進 Discord。
  </FeatureCard>
</div>

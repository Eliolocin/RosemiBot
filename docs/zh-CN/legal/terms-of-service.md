## 1) 术语定义

为清晰起见，本文件通篇使用以下术语：

- **Server**：部署了 TomoriBot 的 Discord 服务器或社群
- **记忆**：通过指令教给 TomoriBot 的事实或信息，或它通过 `remember_this_fact` 函数工具自学到的这类事实
- **Persona/Preset**：可配置的性格与行为画像，会改变 TomoriBot 的回复方式
- **提供方**：你配置 TomoriBot 使用的第三方 AI 或搜索服务（例如 Google、NovelAI、OpenRouter、Brave Search）
- **Hosted Instance**：作为 Discord 公开 bot 维护的官方 TomoriBot 服务，区别于自部署的副本
- **API 密钥**：你提供用来把 TomoriBot 连接到你所选 Provider 的认证凭据
- **Trigger**：导致 TomoriBot 使用你配置的提供方在某个 Discord 文字频道里生成回复的事件，例如：提及 bot、回复它的消息、使用需要 AI 或搜索处理的斜杠指令，或者在开启自动回复的频道里发消息。Trigger 会消耗你提供方账户的 API 额度或词元。
- **Server Manager**：有权为某个 Server 配置 TomoriBot 的成员，例如运行 `/setup` 的那位成员

## 2) 服务范围

- TomoriBot 是一个 AI 驱动的聊天机器人，通过你配置的外部 Provider 回应 Discord 交互。
- 出于维护、安全或法律原因，我们可以随时更改、暂停或终止 TomoriBot 的某些功能。

## 4) 你的责任

- 不要用 TomoriBot 生成违法、有害或平台不允许的内容，也不要用于骚扰或未经授权的访问尝试。
- 你必须达到 Discord 在你所在国家要求的最低年龄（至少 13 岁）才能使用 TomoriBot。使用本服务即表示你声明自己符合这一年龄要求。
- 你仍需对你提供的内容负责（消息、记忆、人格数据、上传文件）。请确保你有权分享这些内容，并避免放入你不想让所配置的 Provider 处理的敏感数据。
- 请遵守速率限制，不要进行会拖垮服务的刷屏或滥用行为。

## 5) 年龄限制内容

- 会产生成人内容的功能默认关闭，必须由 Server Manager 有意开启。
- 开启这些功能的 Server Manager 确认自己已满 18 岁，并确认相关内容只会出现在 Discord 标记为年龄限制的频道里，这类频道仅成年人可访问。
- 被 Discord 社区准则或法律禁止的内容，无论任何设置、频道标记或年龄确认如何，依然被禁止。
- 如果这些功能看起来正在触达未成年人或正在产生被禁止的内容，我们可以为某个 Server 禁用它们，或者完全移除访问权限。

## 8) 数据处置

- 收集的数据、保留期和使用目的见[隐私政策](/zh-CN/legal/privacy-policy/)。

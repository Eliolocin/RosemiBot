本政策适用于Discord上的TomoriBot官方托管服务，包含个人使用、服务器使用，以及由赞助额度支付的请求。若你自行部署TomoriBot，数据由你自行管理，本政策不适用于你的副本。

## 隐私重点

- TomoriBot会读取近期消息来回复，并将相关上下文传给所选的AI提供方。我们不保存聊天记录副本，但选用的短期记忆功能会保存摘要。
- 我们保留你或服务器选择保存的设置、记忆和文件。有些服务器记忆可能描述未提供这些信息的成员。
- 付费会员会增加账号关联、赞助和使用记录，以提供权益并追踪共享额度。我们不收集你的Patreon密码或信用卡数据。
- 大部分已存数据可用指令查看或删除。订阅记录需要另外联系支持。删除bot数据不会取消Patreon扣款。

## 1）本政策的适用对象

即使从未使用指令，只要TomoriBot会读取其消息的成员，也在适用范围内。服务器管理员必须告知成员bot及本政策的信息。你可通过`/legal privacy-policy`与`/legal terms-of-service`阅读最新文件，或查看[服务条款](/legal/terms-of-service/)。

## 2）保存的数据与用途

我们使用已存数据提供你选择的功能、记住偏好、管理付费访问权，并维持服务运行。

### 2.1）账号与偏好

我们保存你的Discord用户ID、隐私选择，以及你选择存储的个人资料与偏好。我们也保留用量总计，让你查看个人、服务器及其人格的统计。你保存的偏好设置包含是否允许人格主动 @提及 你发起对话（来自人格的提及）。

### 2.2）记忆与服务器设置

我们保存个人记忆与服务器记忆、人格自定义内容、提醒和服务器设置，以提供你设置的功能。

当人格自主开口发起对话时（Natural Nudges），我们会记录说话的人格、频道、是否有人回应以及被提及的成员。我们还会保存该人格针对该对话的私密目标（其中可能提及该成员）。

选用的短期记忆会保存对话摘要。其他已存记忆会保留到删除为止，也可能描述未撰写该记忆的人。

### 2.3）API密钥与连接服务

我们保存你为AI提供方、自定义端点及MCP服务器提供的API密钥、服务位址与验证数据，以及Discord频道与Matrix房间的关联。托管服务也管理订阅访问所需的凭证。存储的凭证均经过加密。

### 2.4）保存的文件

我们保留知识库文件的文字及文件信息，让bot能搜索文件。我们也保存人格图片，以及声音复制使用的语音样本与逐字稿。

### 2.5）服务记录

错误与性能记录用于排查问题，可能包含Discord ID、指令名称及错误详情，但不含对话或消息内容。我们也保存消息标识符，以管理bot送出的消息。

### 2.6）会员与订阅用量

关联Patreon会将你的Discord账号与Patreon会员资格连接。我们会从Patreon取得方案、付款状态及账单日期，以判定你的权益。

我们保留赞助及其授权、额度与支出总计，以及请求的模型、功能、费用、token数量、时间和标识符等信息。受赞助服务器的使用会与该服务器关联，并扣除赞助者的额度。

暂时的登录与会员更新记录用来保护账号关联并防止重复更新。你自己的Patreon登录token在关联完成后不会保留。

## 3）会读取但不保存的数据

TomoriBot为了回复，会暂时读取近期消息、相关媒体、服务器与频道信息，以及可取得的上线状态。这些数据不会保存为聊天记录。短期记忆摘要及你主动保存的文件依上述方式处理。

## 4）谁会收到你的数据

- **AI提供方：**所选提供方会收到文字、图片、影片、语音或文件搜索所需的提示词、相关对话上下文、人格信息及媒体。在人格主动提及某人之前，服务器的模型还会收到该成员的名字、当前活动和近期的个人记忆（除非该成员的隐私等级隐藏了这些信息）。订阅请求使用OpenRouter及所选模型的提供方。我们会向OpenRouter查核支出以管理额度。
- **Patreon：**关联即授权我们确认会员资格。Patreon提供账号与会员更新；付款及付款数据由Patreon及其支付服务商处理。
- **搜索提供方：**使用网络搜索时，搜索提供方会收到搜索词及相关上下文。
- **Matrix：**设置桥接后，消息会在关联的Discord频道与Matrix房间之间共享。
- **托管与存储服务商：**处理及保存执行TomoriBot所需的数据。

这些服务可能在你所在国家以外处理数据，并有各自的隐私与保留政策。我们不出售个人数据；仅为提供你使用的功能，或在法律要求时共享。

## 5）保留多久

| 数据 | 保留时间 |
|---|---|
| 短期记忆摘要 | 默认为最后活动后90天 |
| 错误记录 | 90天 |
| 性能记录与bot消息标识符 | 30天 |
| Natural Nudges 记录 | 30天；人格的私密目标最长保留90天 |
| Patreon会员更新记录 | 默认30天 |
| 已完成或过期的Patreon登录记录 | 默认一小时后可删除 |
| 详细订阅用量 | 90天；若当期结束较晚，当期记录保留至该期结束 |
| 数据库恢复备份 | 七天 |
| 启动时自动备份 | 最多五份；产生新备份时删除旧备份 |
| 会员关联、访问状态、赞助及受管理密钥 | 关联期间；解除关联或清除请联系支持 |
| 解除关联后保留的会员标识符与额度、支出总计 | 解除关联、付费期间结束及提供方密钥删除完成三者中，最晚发生之后90天 |
| 其他已存设置、记忆、凭证及上传文件 | 通过第6节的控件删除为止 |

到期记录会在定期清理时删除。若有特定尚未解决的争议或法律义务，我们可能延长保留相关账务记录，并在不再需要时删除。详细用量删除后，支出总计仍可能保留。已删除数据可能留在保留中的备份内：数据库恢复备份七天后到期，启动备份则保留到被替换。另行制作的恢复或迁移副本会在相关工作完成后删除。

移除bot会保留服务器数据，以供重新邀请时使用；若要删除，请先执行`/nuke`。取消扣款不会删除会员记录。

## 6）查看、导出或删除数据

| 目的 | 操作位置 |
|---|---|
| 控制消息可见性与个人记忆使用 | `/personal config` |
| 停止人格主动 @提及 你发起对话 | `/personal config` > `隐私` > `人格主动提及` |
| 查看或移除个人记忆 | `/personal memories` |
| 查看或移除服务器记忆与文件 | `/memories` |
| 导出个人设置或记忆 | `/export personal config`、`/export personal memories` |
| 导出服务器设置或记忆 | `/export config`、`/export memories` |
| 重置个人设置 | `/reset personal config` |
| 跨服务器清除下述个人数据 | `/personal nuke` |
| 清除服务器数据（仅限管理员） | `/nuke` |

`/personal nuke`会删除个人设置、记忆、已存提供方凭证与配置、使用次数，以及你建立或为你设置的提醒。删除反馈也可能影响人格对其他成员的行为。

你提供的服务器记忆与文件会保留，只移除作者关联；请管理员用`/memories`删除。若共享记忆或文件含有你的个人数据，而你无法让对方删除，请通过第9节直接联系我们。提出审查及删除要求不需要管理员同意。

隐私设置会限制消息可见性及个性化，但不会删除既有记忆。清除数据后仍会保留隐私退出选项，不会悄悄重新启用收集。你对人格主动提及的选择属于个性化设置，因此 `/personal nuke` 会将其清除；如果事后仍想保持关闭，请在清除后再次将其关闭。

订阅可通过订阅面板查看额度、赞助，或停止赞助服务器。续订必须在Patreon取消；停止赞助或删除bot数据都不会停止扣款。

如要访问、解除关联或清除订阅记录，请通过第9节联系我们；一般导出与`/personal nuke`不包含这些记录。解除关联会移除账号关联、访问权、赞助及本机详细用量，并要求删除受管理的提供方密钥。第5节所述的有限账务记录仍可能保留。

## 7）如何保护数据

存储的访问凭证均经过加密。数据库连线经过加密并验证服务器身份。访问权限限于bot执行环境及有基础设施访问权的运维人员。

没有系统能保证完全安全。请避免提供极敏感或有特殊处理要求的数据。

## 8）儿童数据

TomoriBot不以未达所在国家Discord最低年龄（至少13岁）的人为对象。我们不会明知而收集低于该年龄者的数据。若你认为我们持有这类数据，请联系我们，我们会删除。部分提供方及订阅功能有较高年龄要求，详见服务条款。

## 9）联系方式

隐私问题或指令无法处理的要求，请寄信至`bredrumb@gmail.com`，或在[TomoriBot官方支持Discord服务器](https://discord.gg/bjCfHm9QsB)联系我们。个人数据或安全疑虑请通过电子邮件或私信提出，不要发布在公开GitHub issue。

重大变更会通过支持Discord或项目仓库公告，并更新本政策顶端日期。

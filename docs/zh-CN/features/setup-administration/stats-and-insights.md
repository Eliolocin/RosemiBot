TomoriBot跟踪交互指标，以便你可以检查活动趋势、模型代币使用、流行人格和工具调用，或呈现可共享的信息图摘要卡。

## 文字仪表盘

三个命令可打开交互式选项卡式仪表板：

- `/stats personal`：查看自己的使用情况统计数据。
- `/stats persona`：查看该服务器上特定人格的使用统计信息。
- `/stats server`：查看所有成员和人格的服务器范围统计信息。

每个仪表板都包含概述、人格、模型和成本、工具和命令、表达式、最喜欢的人员和排行榜的选项卡。

大多数子命令允许你指定时间范围窗口（例如7天、30天或所有时间）。个人统计数据的范围可以是当前服务器或你使用TomoriBot的所有服务器。

文本仪表板是由调用者控制的持久公共消息。他们将保持交互状态，直到被解除或删除，并且其他成员无法操纵你的仪表板控件。

:::note
令牌计数反映了提供商报告的可用情况（基于字符的估计仅适用于省略令牌指标的提供商）。成本数字按照模型目录中的标价对这些代币进行定价，因此由于即时缓存、提供商折扣或免费套餐配额，它们可能与你的实际账单有所不同。
:::

## 可分享的信息图卡片

运行任一 `/stats generate` 指令，渲染可以直接在聊天中分享的精美摘要图像卡片：

- **`/stats generate personal`**（个人年度回顾）：总结你的个人活动和最常用的人格。
- **`/stats generate persona`**（人格亲和度）：从列表中选择一个人格，突出显示该人格的统计数据以及在此服务器上的主要对话伙伴。
- **`/stats generate server`**（服务器排行榜）：显示全服务器范围内的活动和成员排名。

在 `/personal config` 中将隐私级别设为`完全`的用户无法生成个人统计卡片。

有关卡片如何组成和渲染的详细信息，请参阅[统计信息图表子系统](/en/architecture/subsystems/stats-infographic/)。

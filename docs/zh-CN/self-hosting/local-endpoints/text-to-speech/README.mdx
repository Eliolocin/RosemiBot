直接在你的计算机上生成自然的语音消息和字符语音，无需支付每个字符的费用或将音频流式传输到第三方语音API。

TomoriBot将语音视为自定义端点功能。本地引擎作为HTTP服务器在机器人外部运行并实现`POST /synthesize`； 克隆引擎接收文本以及配置的参考音频样本，而支持VoiceDesign的引擎还可以接收自然语言指令。

## 设置流程

1. 从上面的卡片中选择一个引擎并从`servers/tts/`设置其包装器。
2. 在`/providers`中，选择`Add New Custom Endpoint`并使用API兼容性`tts-clone`。
3. 选择保存的端点并使用其模型下拉列表添加其语音模型、语音源模式和脚本标记。
4. 打开`/config` > `模型` > Switch Models，选择注册的Speech模型。

## 网络访问
{/* anchor: network-access */}

所有TTS本地服务器默认都绑定到`127.0.0.1`，因此只有同一台机器上的bot能访问它们。当TomoriBot运行在Docker中或另一台机器上时，请为服务器设置`TOMORI_TTS_HOST=0.0.0.0`，并用宿主机的地址注册端点，例如`http://host.docker.internal:8015`。

这些服务器没有身份验证：任何能访问该端口的人都可以用你的GPU运行合成。只在可信的网络中绑定到回环以外的地址；如果要把服务器暴露到该网络之外，请在前面放一个带身份验证的反向代理。

每个服务器都读取自己的端口变量（`CHATTERBOX_PORT`、`QWEN3TTS_PORT`、`IRODORI_TTS_PORT`、`FISH_S2_PORT`、`VOXCPM2_PORT`、`COSYVOICE3_PORT`、`MOSS_TTS_PORT`），因此可以用同一个`.env`同时运行多个服务器。`bun run launch`会把`.env`传给它启动的服务器；手动启动的服务器只读取其shell环境。

## 人格语音流程

对于克隆引擎，为每个人格添加并分配一个语音样本：

1. 准备一个干净的剪辑，只有一个扬声器，没有背景音乐。每个引擎都有自己的最佳长度，根据型号从3到30秒不等； 下面的每个引擎指南都带有编号。
2. 在模型 > `TTS参数与语音`下打开`/config`并上传示例。接受任何音频格式； TomoriBot将其转换为单声道WAV，最长130秒。
3. 当引擎从中受益时提供匹配的记录。Fish S2 Pro将存储的参考转录本转发到克隆请求中，VoxCPM2将其用于更高保真度的终极克隆。
4. 在人格 > `语音`下打开`/config`，然后选择人格和语音样本。

130秒上传上限由TomoriBot强制执行。发送剪辑时，每个引擎都会应用自己的参考音频限制，并且这些限制差异很大，以至于适合一个引擎的剪辑可能会被另一个引擎拒绝或部分忽略。上传长剪辑之前请检查引擎指南。

上传大小限制和时长上限是独立的，并且首先运行大小检查。未压缩的WAV立体声44.1 kHz的成本约为每分钟10 MB，因此130秒的DAW导出可能约为22 MB，并且会因太大而被拒绝，而同一剪辑的压缩导出则很容易适应。`SPEECH_SAMPLE_MAX_MB`提高了该大小限制（默认为10 MB）。对于较长的参考剪辑，请将其导出为FLAC、MP3或OGG，而不是WAV：TomoriBot在存储之前将任何可接受的格式转换为22.05 kHz的单声道WAV，因此压缩上传不会影响质量。

对于Qwen3-TTS、MOSS-VoiceGenerator、IrodoriTTS或VoxCPM2 VoiceDesign，请跳过音频示例并使用`/config`中的人格 > `语音`保存人格的自然语言语音描述。CosyVoice 3使用克隆模式和参考样本，并通过`voice_instructions`接受一次性交付指示。

ElevenLabs用户应在`/providers`中选择`添加新提供方`和`ElevenLabs`； 它将语音和转录端点注册在一起。

TomoriBot在合成之前从生成的语音脚本中剥离Discord自定义表情符号语法，例如`:pepega:`或`<:pepega:123456789012345678>`。除非语音端点使用用于IrodoriTTS的表情符号标记，否则Unicode表情符号也会被删除。当Chatterbox Turbo和Fish S2 Pro等端点的脚本标记设置为`方括号标签`时，会保留括号标记。

VoxCPM2使用`纯文本`脚本标记。其语音设计和说话风格控件穿过TomoriBot的`instruct`字段，VoxCPM2包装器将它们转换为模型的原生带括号的自然语言控制语法。

CosyVoice 3还使用`纯文本`脚本标记。它将转录本支持的引用映射到零次克隆，将无转录本引用映射到跨语言克隆，并将`voice_instructions`映射到其指令条件路径。内嵌括号标签被删除，因为CosyVoice指令适用于整个话语。

TomoriBotはインタラクションメトリクスを追跡するため、アクティビティの傾向、モデルトークンの使用状況、人気のあるペルソナ、ツール呼び出しを検査したり、共有可能なインフォグラフィックサマリー カードをレンダリングしたりできます。

## テキストダッシュボード

3つのコマンドにより、対話型のタブ付きダッシュボードが開きます。

- `/stats personal`: 独自の使用状況統計を表示します。
- `/stats persona`: このサーバー上の特定のペルソナの使用統計を表示します。
- `/stats server`: すべてのメンバーとペルソナにわたるサーバー全体の統計を表示します。

各ダッシュボードには、概要、ペルソナ、モデルとコスト、ツールとコマンド、式、お気に入りのユーザー、およびリーダーボードのタブが含まれています。

ほとんどのサブコマンドでは、期間枠 (7日、30日、または常時など) を指定できます。個人統計は、現在のサーバーまたはTomoriBotを使用するすべてのサーバーにスコープを設定できます。

テキストダッシュボードは、実行者によって制御される耐久性のあるパブリックメッセージです。無視または削除されるまで対話型のままであり、他のメンバーはダッシュボードコントロールを操作できません。

:::note
トークン数は、プロバイダーによって報告された使用量を反映します (利用可能な場合) (文字ベースの推定値は、トークンメトリックを省略するプロバイダーにのみ使用されます)。コストの数値は、モデルカタログのリストレートでトークンの価格を設定しているため、プロンプトキャッシュ、プロバイダーの割引、または無料利用枠の割り当てにより、実際の請求額と異なる場合があります。
:::

## 共有可能なインフォグラフィックカード

`/stats generate`を実行して、チャットで直接共有できる洗練された概要イメージカードをレンダリングします。

- **パーソナルラップ**: あなたの個人的なアクティビティとお気に入りのペルソナを要約します。
- **ペルソナアフィニティ**: 特定のペルソナの統計情報と、このサーバー上の上位の会話パートナーを強調表示します。
- **サーバー リーダーボード**: サーバー全体のアクティビティとメンバーの順位を表示します。

`/personal config`でプライバシー レベルが`完全`に設定されているユーザーは、個人統計カードを生成できません。

カードの構成とレンダリングの詳細については、[統計インフォグラフィックサブシステム](/en/architecture/subsystems/stats-infographic/) を参照してください。

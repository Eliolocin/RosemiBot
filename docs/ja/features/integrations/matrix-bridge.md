マトリックスルームをDiscordチャネルにブリッジして、両方のプラットフォーム間でチャットできるようにします。Matrixから送信されたメッセージは、WebhookメッセージとしてDiscordに表示され、TomoriBotはMatrixルームに直接応答します。

appserviceのホスティングとデプロイメントのアーキテクチャについては、[マトリックスブリッジアーキテクチャ](/en/architecture/integrations/matrix/bridge/) を参照してください。

## セットアップ

1. Matrixボットアカウントを暗号化されていないMatrixルームに招待します。
2. そのルームの内部ルームIDをコピーします (ほとんどのクライアント: `Room Settings` > `高度な設定` > `Internal Room ID`、`!abc:matrix.org`のような形式)。
3. ブリッジしたいDiscordチャネルで`/matrix link`を実行し、ルームIDを貼り付けます。

ボットが参加すると、Matrixに確認が投稿されますが、`/matrix link`を使用してDiscordからリンクを完了する必要があります。ブリッジされたチャネルを後で切断するには、`/matrix unlink`を実行します。

## Matrixからの使用

- ルームがリンクされたら、通常どおりチャットします。マトリックスメッセージはDiscordチャネルに中継されます。
- TomoriBotはマトリックスルームに返信します。
- サポートされているマトリックステキストコマンドは、`/kill`および`/refresh`です。

## 現在の制限事項

- Matrixからのスラッシュコマンドはありません (`/kill`と`/refresh`を超える)。
- ダイレクトメッセージやDMベースのクールダウンリマインダーはありません。
- マトリックスアバターはボットの視覚機能には表示されません。
- メッセージの固定は利用できません。
- カスタム絵文字と複雑な書式設定は確実に表示されません。リレーをプレーンテキストとして埋め込みます。
- Matrixユーザーの個人的な記憶は、属性付きのサーバーの記憶にフォールバックします。

## 備考

- ボットが自動的に参加しない場合は、Matrixボットアカウントを手動で招待し、`/matrix link`を再実行します。
- ルームの作成後にマトリックス暗号化を無効にすることはできません。暗号化されたルームは、暗号化されていない新しいルームに置き換える必要があります。
- チャネルのリンクを解除するには、`/matrix unlink`を使用します。
- 問題が上記にリストされていない場合は、`/support discord`を使用してサポートサーバーに報告してください。

`/help`で、`プラグイン`を選択し、次に`Matrix`を選択して、Discordの対話型ウォークスルーを実行します。

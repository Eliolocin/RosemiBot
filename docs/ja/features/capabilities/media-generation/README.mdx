TomoriBotは、チャット内で画像、短いビデオ、音声メッセージなどのメディアを直接作成できます。わかりやすい言葉で彼女に尋ねるか (「... を描いて」、「音声メッセージとして送信して」)、または`/generate`コマンドを使用します。どの機能が利用できるかは、構成されたプロバイダーによって異なります。[プロバイダーとモデル](/ja/features/setup-administration/providers-and-models/) を参照してください。

  <LinkCard title="声: TTS & STT" href="/ja/features/capabilities/media-generation/tts-and-stt/"

:::note
すべてのプロバイダーがすべての機能をサポートしているわけではありません。ローカル生成 (ComfyUI、ローカル音声サーバー) はセルフホスト型インスタンスで利用できます。[セルフホスティング](/ja/self-hosting/)を参照してください。
:::

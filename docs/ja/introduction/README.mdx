TomoriBotは、Discord用の無料かつオープンソースのAIエージェントおよびロールプレイシステムです。このプロジェクトは、SillyTavernや、提供が終了したDiscordのClydeにインスパイアされており、パーソナルAIコンパニオンやロールプレイキャラクターをDiscordサーバーに直接もたらすことを目的としています。簡単に言えば、トモリはDiscordに組み込まれたAIのためのエージェント兼ロールプレイ用の仕組みです。

![トモリの構成要素](/img/docs/intro/00-tomori-formula.png)
<small style={{ display: 'block', textAlign: 'center', fontStyle: 'italic', color: 'var(--sl-color-gray-3)' }}>Discord、SillyTavern、そしてOpenClawの恐るべき三位一体のようなものです</small>

Tomo(友)-Ri(里)、大まかに「友の家」を意味する読み方をし、トモリはDMやDiscordサーバーのメンバー全員のために、あなた自身の実用的なアシスタント、カスタマイズ可能なコンパニオン、そして/あるいはロールプレイパートナーのための居場所となります。トモリは初心者を念頭に置いて構築されているため、AIエージェントに初めて触れる人でも、トモリと一緒に学ぶことができます。

公開されているインスタンスを今すぐ招待することもできますし、データを完全に制御するために独自のインスタンスをセルフホストすることもできます（詳細は[クイックスタート](/ja/introduction/quickstart/)をご覧ください）。

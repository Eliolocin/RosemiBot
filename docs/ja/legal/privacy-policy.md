本ポリシーは、個人利用、サーバーでの利用、スポンサーの利用枠を使うリクエストを含む、Discord上の公式ホスト版TomoriBotを対象とします。TomoriBotをセルフホストする場合、データは自身で管理し、本ポリシーはそのコピーには適用されません。

## プライバシーの概要

- TomoriBotは応答のために直近のメッセージを読み、関連する文脈を選択されたAIプロバイダーに送信します。チャット履歴のコピーは保存しませんが、任意の短期記憶機能は要約を保存します。
- 利用者やサーバーが保存を選んだ設定、記憶、ファイルを保持します。サーバーの記憶には、その情報を提供していないメンバーに関する内容が含まれる場合があります。
- 有料メンバーシップでは、特典の提供と共通の利用枠の管理のため、アカウントの連携、スポンサー設定、利用記録が追加されます。Patreonのパスワードやカード情報は収集しません。
- 保存データの大半はコマンドで確認・削除できます。サブスクリプション記録には別途サポートへの依頼が必要です。ボットのデータを削除してもPatreonの請求は停止しません。

## 1) 本ポリシーの対象

コマンドを一度も使っていなくても、TomoriBotがメッセージを読み取るメンバーは対象です。サーバー管理者はボットと本ポリシーについてメンバーに知らせる必要があります。最新の文書は`/legal privacy-policy`と`/legal terms-of-service`で確認できます。[利用規約](/legal/terms-of-service/)もご覧ください。

## 2) 保存するデータと目的

選択した機能の提供、利用者の設定の記憶、有料アクセスの管理、サービスの運用に保存データを使用します。

### 2.1) アカウントと設定

DiscordユーザーID、プライバシーの選択、保存を選んだプロフィール情報と設定を保存します。また、利用者、サーバー、ペルソナの統計を表示できるよう、利用量の合計を保存します。保存される設定には、ペルソナがあなたにメンションして会話を始めることを許可するかどうか（ペルソナからのメンション）が含まれます。

### 2.2) 記憶とサーバー設定

設定した機能を提供するため、個人とサーバーの記憶、ペルソナのカスタマイズ、リマインダー、サーバー設定を保存します。

ペルソナが自発的に会話を始めたとき（Natural Nudges）、どのペルソナが話したか、チャンネル、誰かが返答したか、およびメンションされたメンバーを記録します。また、その会話におけるペルソナの非公開の目標（そのメンバーに言及している場合があります）も保存します。

任意の短期記憶機能は会話の要約を保存します。それ以外の保存済み記憶は削除されるまで残り、記述した本人以外の人に関する内容を含む場合があります。

### 2.3) APIキーと接続先サービス

AIプロバイダー、カスタムエンドポイント、MCPサーバー用に提供されたAPIキー、サービスのアドレス、認証情報、およびDiscordチャンネルとMatrixルームの連携を保存します。ホスト版サービスは、サブスクリプションのアクセス用認証情報も管理します。保存する認証情報は暗号化されます。

### 2.4) 保存するファイル

ボットが検索できるよう、ナレッジベース文書のテキストとファイル情報を保持します。ペルソナ画像と、音声クローン用の音声サンプルおよび書き起こしも保存します。

### 2.5) サービスの記録

エラーとパフォーマンスの記録は問題の調査に使用します。Discord ID、コマンド名、エラーの詳細を含む場合がありますが、会話やメッセージ本文は含みません。また、ボットが送信したメッセージを管理するため、その識別子を保存します。

### 2.6) メンバーシップとサブスクリプションの利用

Patreonとの連携により、DiscordアカウントがPatreonのメンバーシップに結び付けられます。特典を判断するため、Patreonからティア、支払い状況、請求日を受け取ります。

スポンサー設定、その承認、利用枠と消費額の合計、およびモデル、機能、費用、トークン数、時刻、識別子などのリクエスト情報を保持します。スポンサー対象サーバーの利用はそのサーバーに関連付けられ、スポンサーの利用枠から差し引かれます。

一時的なログイン記録とメンバーシップ更新記録は、アカウント連携の保護と重複更新の防止に使用します。利用者自身のPatreonログイントークンは、連携後は保存しません。

## 3) 保存せずに読み取るもの

応答のため、直近のメッセージ、関連するメディア、サーバーとチャンネルの情報、取得可能なオンライン状態を一時的に読み取ります。これらはチャット履歴として保存しません。短期記憶の要約や意図的に保存したファイルは、上記のとおり取り扱います。

## 4) データの送信先

- **AIプロバイダー：**選択されたプロバイダーには、テキスト、画像、動画、音声、文書検索に必要なプロンプト、関連する会話の文脈、ペルソナ情報、メディアを送ります。ペルソナが誰かにメンションする前に、サーバーのモデルはそのメンバーの名前、現在のアクティビティ、最近の個人の記憶も受け取ります（プライバシーレベルでこれらが非表示になっている場合を除く）。サブスクリプションのリクエストはOpenRouterと選択したモデルのプロバイダーを使用します。利用枠を管理するため、OpenRouterで消費額を確認します。
- **Patreon：**連携によってメンバーシップの確認が許可されます。Patreonはアカウントとメンバーシップの更新を提供し、Patreonとその決済事業者が支払いと決済情報を取り扱います。
- **検索プロバイダー：**ウェブ検索を使用する際、検索クエリと関連する文脈を受け取ります。
- **Matrix：**ブリッジが設定されている場合、連携したDiscordチャンネルとMatrixルームの間でメッセージを共有します。
- **ホスティング・ストレージ事業者：**TomoriBotの運用に必要なデータを処理・保存します。

これらのサービスは、利用者の居住国外でデータを処理する場合があり、独自のプライバシー・保持ポリシーを持ちます。個人データは販売しません。利用する機能の提供や、法令により必要な場合に共有します。

## 5) 保持期間

| データ | 保持期間 |
|---|---|
| 短期記憶の要約 | 既定では最後の活動から90日 |
| エラーログ | 90日 |
| パフォーマンス記録とボットのメッセージ識別子 | 30日 |
| Natural Nudgesの記録 | 30日。ペルソナの非公開の目標は最大90日 |
| Patreonのメンバーシップ更新記録 | 既定では30日 |
| 完了または期限切れのPatreonログイン記録 | 既定では1時間後から削除対象 |
| サブスクリプション利用の詳細 | 90日。ただし、現在の利用期間がそれより後に終了する場合は、その期間の終了まで |
| データベース復旧用バックアップ | 7日 |
| 起動時の自動バックアップ | 最大5個。新しいものを作成する際に古いものを削除 |
| メンバーシップ連携、アクセス状況、スポンサー設定、管理対象キー | 連携中。解除や消去はサポートに依頼してください |
| 連携解除後に残るメンバーシップ識別子と利用枠・消費額の合計 | 連携解除、有料期間の終了、プロバイダーキー削除の完了のうち、最も遅い時点から90日 |
| その他の保存済み設定、記憶、認証情報、アップロード | 第6項の操作で削除するまで |

期限を過ぎた記録は定期クリーンアップで削除します。特定の未解決の紛争や法的義務のため、関連する会計記録をより長く保持し、その必要がなくなった時点で削除する場合があります。詳細な利用記録の削除後も、消費額の合計が残る場合があります。削除したデータが保持中のバックアップに残る場合があります。データベース復旧用バックアップは7日で期限切れになり、起動時バックアップは置き換えられるまで残ります。個別の復旧・移行用コピーは、その作業が完了した時点で削除します。

ボットを削除しても、再招待に備えてサーバーデータは残ります。削除したい場合は先に`/nuke`を実行してください。請求を解約してもメンバーシップ記録は削除されません。

## 6) データの確認・エクスポート・削除

| 目的 | 操作 |
|---|---|
| メッセージの可視性と個人の記憶の利用を管理 | `/personal config` |
| ペルソナがメンションして会話を始めるのを停止 | `/personal config` > `プライバシー` > `ペルソナからのメンション` |
| 個人の記憶の確認・削除 | `/personal memories` |
| サーバーの記憶と文書の確認・削除 | `/memories` |
| 個人設定や記憶のエクスポート | `/export personal config`、`/export personal memories` |
| サーバー設定や記憶のエクスポート | `/export config`、`/export memories` |
| 個人設定のリセット | `/reset personal config` |
| 以下の個人データをサーバー横断で消去 | `/personal nuke` |
| サーバーデータの消去（管理者のみ） | `/nuke` |

`/personal nuke`は個人設定、記憶、保存済みプロバイダー認証情報と設定、利用回数、および自身が作成したか、自身に設定されたリマインダーを削除します。フィードバックの削除によって、他のメンバーに対するペルソナの振る舞いにも影響する場合があります。

自身が作成したサーバーの記憶や文書は残り、作成者との関連付けのみを削除します。特定の項目の削除は管理者に`/memories`で依頼してください。共有の記憶や文書に自身の個人データが含まれ、削除してもらえない場合は、第9項の連絡先へ直接お問い合わせください。確認と削除の依頼に管理者の許可は不要です。

プライバシー設定はメッセージの可視性と個別化を制限しますが、既存の記憶は削除しません。消去後もプライバシーのオプトアウトは維持され、収集が自動的に再有効化されることはありません。ペルソナからのメンションの設定は個人設定の一部であるため、`/personal nuke` によって消去されます。引き続きオフにしたい場合は、消去後に再度ペルソナからのメンションをオフにしてください。

サブスクリプションパネルで利用枠やスポンサー設定を確認し、サーバーへのスポンサー提供を停止できます。更新の解約はPatreonで行ってください。スポンサー提供の停止やボットデータの削除では請求は停止しません。

サブスクリプション記録へのアクセス、連携解除、消去は、第9項の連絡先へ依頼してください。通常のエクスポートや`/personal nuke`には含まれません。連携解除はアカウント連携、アクセス、スポンサー設定、ローカルの詳細な利用記録を削除し、管理対象プロバイダーキーの削除を要求します。第5項に記載の限定的な会計記録は残る場合があります。

## 7) データの保護

保存するアクセス認証情報は暗号化されます。データベース接続は暗号化し、接続先サーバーの身元を検証します。アクセスはボットの実行環境とインフラへのアクセス権限を持つ運用者に制限します。

完全に安全なシステムはありません。極めて機微な情報や、特別な取り扱いが必要なデータの提供は避けてください。

## 8) 子どものデータ

TomoriBotは、居住国でDiscordが定める最低年齢（少なくとも13歳）に達していない人を対象としていません。その年齢未満の人から故意にデータを収集しません。該当するデータを当方が保持していると思われる場合はご連絡ください。削除します。プロバイダーやサブスクリプション機能によっては、利用規約に記載のとおり、より高い年齢要件があります。

かわいいマスコットと架空のストーリーがないAIプロジェクトなんてあり得ませんよね。設定上、トモリはアンドロイドのタイプであり、機械の角、尻尾、そして目立つバーコードタグ（通常は耳に付いている）が特徴です。トモリは姿を変えることができます（これが複数のペルソナに分かれることができる理由です）。

トモリには複数の異なる生産ラインがあり、そのほとんどは人間をアシストするためのものですが、以下に見るように、それぞれに異なる特技、組み込みの性格、そして*Tomoriverse*での物語があります。

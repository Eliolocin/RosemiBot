ローカルマシンまたはプライベートネットワーク上で実行されているTomoriBotサーバーをModel Context Protocol ([MCP](https://modelcontextprotocol.io/)) に接続して、カスタムローカルツールを提供します。

リモートHTTPSサーバーについては、[ツールと拡張機能](/ja/features/capabilities/tools-and-extensions/#mcp-servers) を参照してください。ローカルMCPエンドポイントにはセルフホスト型インスタンスが必要です。

:::caution[Self-hosting only]
ローカルMCPサーバーは、セルフホスト型インスタンスでのみサポートされます。パブリックホスト型ボットはHTTPSを必要とし、セキュリティのためにローカル/プライベートアドレスをブロックするため、`localhost`またはLAN上のサーバーに到達できません。
:::

## 1. ローカルMCPサーバーを実行する

ローカルポートでHTTP/SSEトランスポートを公開するMCPサーバーを起動します。たとえば、多くのMCPサーバーはノード経由で実行されます。

```sh
npx -y <some-mcp-server> --port 3000
```

正確なコマンドは、実行しているサーバーによって異なります。出力されるURLとトランスポートパス (通常は`http://localhost:3000/sse`) に注目してください。

## 2. Discordに登録する

`/config` > `プラグイン` > [MCPサーバー] を開き、`+ MCPを追加`を選択し、`サーバーURL`フィールドをローカルエンドポイントに設定し、`サーバータイプ`をデフォルトの`汎用`設定のままにします。

```text
http://localhost:3000/sse
```

`認証トークン（任意）`を空白のままにします: ローカルサーバーは認証トークンを必要としません。

## 3. 管理する

[構成] ページを開き、サーバーの行で`削除`を選択します。確認すると登録が解除され、すぐに切断され、スロットが解放されます。

## セキュリティ

:::danger[Only add MCP servers you trust]
自分で実行しているローカルサーバーでも、コードが信頼できない場合は誤動作する可能性があります。悪意のあるMCPサーバーは、モデルをプロンプト挿入したり、そのツールに渡されたデータを抽出したり、TomoriBotが中継する有害な結果を返したりする可能性があります。配線する前に、MCPサーバーの動作を確認してください。
:::

オンラインMCPフローと完全なセキュリティの詳細については、[ツールと拡張機能](/ja/features/capabilities/tools-and-extensions/#mcp-servers) を参照してください。

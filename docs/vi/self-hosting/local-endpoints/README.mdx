## Khởi động các máy chủ cục bộ bằng `bun run launch`

Thay vì khởi động các máy chủ cục bộ một cách thủ công, hãy sử dụng `bun run launch` để khởi động các máy chủ được yêu cầu, đợi chúng sẵn sàng, sau đó tự động chạy bot ở chế độ theo dõi:

```sh
# Chỉ bot, giống hệt bun run dev
bun run launch

# Đi kèm các container Docker SearXNG và Crawl4AI
bun run launch --searxng --crawl4ai

# Đi kèm máy chủ TTS cục bộ (trước tiên phải thiết lập venv, xem hướng dẫn Chuyển văn bản thành giọng nói bên dưới)
bun run launch --qwen3tts
bun run launch --fishs2
bun run launch --voxcpm2
bun run launch --cosyvoice3

# Xem tất cả các cờ khả dụng
bun run launch --help
```

Các cờ khả dụng: `--searxng`, `--crawl4ai`, `--qwen3tts`, `--chatterbox`, `--irodoritts`, `--voxcpm2`, `--fishs2`, `--cosyvoice3`, `--moss`, `--whisperx`

Các máy chủ dựa trên Docker (`--searxng`, `--crawl4ai`) được tạo trong lần chạy đầu tiên và được tái sử dụng trong các lần chạy tiếp theo. Các máy chủ TTS/STT Python yêu cầu môi trường ảo venv phải được thiết lập một lần từ trước; xem các hướng dẫn thiết lập riêng lẻ trong [Chuyển văn bản thành giọng nói](/vi/self-hosting/local-endpoints/text-to-speech/) và [Chuyển giọng nói thành văn bản](/vi/self-hosting/local-endpoints/speech-to-text/).

Ctrl+C sẽ dừng bot và mọi tiến trình máy chủ Python. Các Docker container được giữ chạy có chủ đích. Hãy dừng chúng thủ công bằng `docker stop searxng` / `docker stop crawl4ai` khi hoàn tất.

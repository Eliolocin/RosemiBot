## Iniciar servidores locales con `bun run launch`

En lugar de iniciar los servidores locales manualmente, usa `bun run launch` que inicia los servidores solicitados, espera a que estén listos y luego lanza el bot en modo de observación automáticamente:

```sh
# Solo el bot, idéntico a bun run dev
bun run launch

# Con los contenedores Docker de SearXNG y Crawl4AI
bun run launch --searxng --crawl4ai

# Con un servidor TTS local (venv debe configurarse primero; consulta la guía de Texto a voz a continuación)
bun run launch --qwen3tts
bun run launch --fishs2
bun run launch --voxcpm2
bun run launch --cosyvoice3

# Ver todas las banderas disponibles
bun run launch --help
```

Banderas disponibles: `--searxng`, `--crawl4ai`, `--qwen3tts`, `--chatterbox`, `--irodoritts`, `--voxcpm2`, `--fishs2`, `--cosyvoice3`, `--moss`, `--whisperx`

Los contenedores Docker (`--searxng`, `--crawl4ai`) se crean en la primera ejecución y se reutilizan en ejecuciones posteriores. Los servidores de texto a voz y voz a texto de Python requieren que su venv se configure una vez de antemano; consulta las guías de configuración individuales en [Texto a voz](/es-419/self-hosting/local-endpoints/text-to-speech/) y [Voz a texto](/es-419/self-hosting/local-endpoints/speech-to-text/).

Ctrl+C detiene el bot y cualquier proceso de servidor de Python. Los contenedores de Docker se dejan ejecutando intencionalmente. Detenlos manualmente con `docker stop searxng` / `docker stop crawl4ai` cuando termines.

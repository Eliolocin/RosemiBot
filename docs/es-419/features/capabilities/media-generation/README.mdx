TomoriBot puede crear medios directamente en el chat: imágenes, vídeos cortos y mensajes de voz hablados. Pregúntale en lenguaje sencillo ("dibújame un...", "envíalo como mensaje de voz") o utiliza los comandos `/generate`. Las capacidades disponibles dependen de su proveedor configurado; consulte [Proveedores y modelos](/es-419/features/setup-administration/providers-and-models/).

:::note
No todos los proveedores admiten todas las capacidades. La generación local (ComfyUI, servidores de voz locales) está disponible en instancias autohospedadas; consulte [Autohospedaje](/es-419/self-hosting/).
:::

TomoriBot pode criar mídia diretamente no chat: imagens, vídeos curtos e mensagens de voz faladas. Pergunte a ela em linguagem simples ("desenhe-me um...", "envie isso como uma mensagem de voz") ou use os comandos `/generate`. Quais recursos estão disponíveis dependem do seu provedor configurado; consulte [Provedores e Modelos](/pt-BR/features/setup-administration/providers-and-models/).

Nem todo provedor oferece suporte a todos os recursos. A geração local (ComfyUI, servidores de voz locais) está disponível em instâncias auto-hospedadas; consulte [Auto-hospedagem](/pt-BR/self-hosting/).

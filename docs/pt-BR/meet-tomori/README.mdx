O que é um projeto de ambiente de IA sem sua mascote fofa e história fictícia? Na tradição, uma Tomori é um tipo de androide, caracterizada por seus chifres mecânicos, cauda e etiquetas de código de barras proeminentes (geralmente presas na orelha). Elas são capazes de mudar de forma (a razão pela qual ela pode se dividir em múltiplas personas).

Existem várias linhas de produção diferentes para as Tomoris, a maioria das quais é para ajudar os humanos, mas como visto abaixo, cada uma tem especialidades diferentes, personalidades integradas e histórias no *Tomoriverse*:
